# 🏥 My-HealthKey

> **Procure os remédios mais baratos perto de você, sempre prezando pela sua saúde e seu tempo.**

My-HealthKey é uma plataforma focada em resolver um dos maiores problemas na hora de comprar medicamentos: a variação de preços e a perda de tempo buscando de farmácia em farmácia. 

## 🎯 O Pitch (Por que o My-HealthKey existe?)

**O Problema:** Quando precisamos de um remédio, muitas vezes não estamos nas melhores condições de saúde ou não temos tempo a perder. Ir de farmácia em farmácia ou pesquisar em vários sites diferentes para encontrar o melhor preço é exaustivo.

**A Solução:** O My-HealthKey centraliza a busca. Com apenas alguns cliques, o usuário pesquisa o medicamento desejado e a plataforma compara os preços nas farmácias mais próximas (como "Loja A", "Loja B", etc.), mostrando descontos reais e onde encontrar o melhor custo-benefício.

**Nosso Diferencial:** 
- Rapidez na busca de medicamentos.
- Georreferenciamento para farmácias próximas.
- Transparência total de preços e promoções (ex: "20% OFF").

## ✨ Funcionalidades Principais

- 🔍 **Busca Inteligente:** Encontre medicamentos pelo nome ou princípio ativo rapidamente.
- 💰 **Comparação de Preços:** Veja qual farmácia próxima tem o produto mais barato.
- 📱 **Interface Acessível e Moderna:** Design limpo e focado no usuário.
- 🔐 **Área do Usuário:** Cadastro e login para salvar buscas recentes e preferências.

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído utilizando as tecnologias mais modernas do ecossistema web:

- **[Next.js 16](https://nextjs.org/)** - Framework React com renderização híbrida e rotas otimizadas (App Router).
- **[React 19](https://react.dev/)** - Biblioteca base para construção da interface de usuário.
- **[Tailwind CSS v4](https://tailwindcss.com/)** - Estilização utilitária super-rápida.
- **[Shadcn UI](https://ui.shadcn.com/) & [Base UI](https://base-ui.com/)** - Componentes acessíveis e personalizáveis.
- **[Biome](https://biomejs.dev/)** - Ferramenta super-rápida para formatação e linting do código.
- **Phosphor Icons** - Ícones limpos e consistentes.

## 🚀 Como Executar o Projeto Localmente

Siga os passos abaixo para rodar o ambiente de desenvolvimento na sua máquina:

1. **Instale as dependências:**
   ```bash
   npm install
   ```

2. **Inicie o servidor de desenvolvimento:**
   ```bash
   npm run dev
   ```

3. Abra [http://localhost:3000](http://localhost:3000) no seu navegador para ver o resultado.
